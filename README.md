# CMC Capital website starter

A responsive static landing page for CMC Capital, using black, white and emerald green. Includes sections for market insights, equity research, financial education, publications and a newsletter sign-up demo.

## Preview locally

1. Download and unzip the project.
2. Open `index.html` in a browser. An internet connection is used for Google Fonts; the site otherwise runs as static files.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a new public repository, for example `cmc-capital-website`.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. GitHub will show the public URL in the Pages settings.

## Before launch

- Confirm the brand name and check availability of any desired domain.
- Replace placeholder publication copy with real material and publish only content you have rights to use.
- Connect the email form to a mailing-list provider; it currently does not collect or send email addresses.
- Add privacy, contact and editorial/disclaimer pages as needed.
- Market research and education content should be reviewed for accuracy. The current footer says the site is educational and not investment advice.
